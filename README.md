## Running a notebook

Open the notebook, click **Open in Colab** at the top, and run the cells. Nothing to install,
nothing to upload — the data files are read straight out of this repository.

To keep your own changes, use **File → Save a copy in Drive** in Colab. Editing a notebook here
does not save anything, and you cannot commit to this repository.

If you have never used Python before, **`Session 01/lab1_python_tutorial.ipynb` is required
preparation before the first class.** It is self-paced and assumes nothing.
