## Running a notebook

Open the notebook, click **Open in Colab** at the top, and run the cells top to bottom. The first
cell fetches the datasets, so there is nothing to upload and nothing to install.

To keep your own changes, use **File → Save a copy in Drive** in Colab. Editing a notebook here
does not save anything, and you cannot commit to this repository.

`Session 01/lab1_python_tutorial.ipynb` is a self-paced Python, NumPy and pandas tutorial that
assumes no prior programming. **The syllabus says when it is expected** — check there rather than
here. One cell in it raises an error on purpose; that is a teaching example, not a bug.
